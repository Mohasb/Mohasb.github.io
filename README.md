# Mi portfolio

Portfolio personal publicado con GitHub Pages.

## Estructura
- `index.html`: toda la web (HTML, CSS y JS en un solo archivo).
- `img/mhcars-preview.webm`, `img/mhcars-preview.mp4` e `img/mhcars-poster.webp`: vídeo de MHCars (proyecto de DAW) que se ve con la demo apagada. Se regeneran con `cd tools/preview && npm install && npm run grabar`.
- `img/dam-android.png` e `img/dam-windows.png`: capturas de la app Flutter en cada plataforma.
- `assets/i18n/`: traducciones (en, fr, de, pt, it). El español está en `index.html`.
- `cv.pdf`: currículum. No se publica (`.gitignore`): se pide con el formulario de la web.

## Demos en vivo
Cuando publiques las demos, pega sus URL en el objeto `DEMOS` de `index.html`.

Busca `✏️ EDITA` en `index.html` para encontrar todo lo que falta personalizar.
